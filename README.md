# Task 4: Interactive Business Dashboard

## 📌 Project Overview
This project focuses on designing an interactive business dashboard using **Microsoft Power BI** to analyze e-commerce sales data. The dashboard helps stakeholders understand revenue performance, customer activity, product category performance, and regional sales trends.

## 🎯 Objectives
- Track total revenue, total orders, and total customers.
- Calculate Average Order Value (AOV).
- Analyze revenue trends over time.
- Compare revenue across product categories and regions.
- Provide interactive filtering for business analysis.
- Present findings through clear and professional visualizations.

## 🛠️ Tools and Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- CSV dataset
- Microsoft PowerPoint

**Dataset name:** `ecommerce_sales_analytics_5000.csv`

## 📊 Dashboard Features

### 1. KPI Cards
- Total Revenue

### 2. Revenue Over Time
A line chart showing how revenue changes over the selected date range.

### 3. Revenue by Category
A bar chart comparing revenue generated by each product category.

### 4. Revenue by Region
A column chart comparing revenue across different regions.

## 🧮 Key DAX Measures

**Total Revenue**
```DAX
Total Revenue =
SUM('ecommerce_sales_analytics_5000'[revenue])
```

**Total Orders**
```DAX
Total Orders =
DISTINCTCOUNT('ecommerce_sales_analytics_5000'[order_id])
```

**Total Customers**
```DAX
Total Customers =
DISTINCTCOUNT('ecommerce_sales_analytics_5000'[customer_id])
```

**Average Order Value**
```DAX
Average Order Value =
DIVIDE([Total Revenue], [Total Orders], 0)
```
